# Valentine Quiz 💖

💌 **An interactive, playful Valentine’s Day website made as a surprise gift.**

This special website includes:  
- 🎀 **Floating doll** on the welcome screen  
- 😆 **Runaway “No” buttons** for fun teasing  
- 📸 **Memory photos** that change on tap with zoom & heart effects  
- 💖 **Love meter** filling as answers are chosen  
- 🎆 **Proposal screen** with fireworks and typing love letter  
- Fully **mobile-friendly** and interactive  

**How to Use:**  
1. Open `index.html` in a browser  
2. Click **Start** to begin the quiz  
3. Tap/click answers and enjoy the interactive features
4. Tap on the Photo to change and see the Memories
5. Watch the proposal surprise at the end 💌  

**Technologies Used:**  
- HTML  
- CSS  
- JavaScript
